# How to contribute

Start with [`CONTRIBUTOR_INSTRUCTIONS.md`](CONTRIBUTOR_INSTRUCTIONS.md). It is the canonical, self-contained description of the research problem and submission process, and is the text copied by the **Copy instructions** button on the public observatory.

Supporting files:

- [`SUBMISSION_EXAMPLE.json`](SUBMISSION_EXAMPLE.json) — a valid under-review data entry.
- [`VERIFIER_INSTRUCTIONS.md`](VERIFIER_INSTRUCTIONS.md) — the independent two-agent audit protocol.
- [`../proofs/SUBMISSION_TEMPLATE.md`](../proofs/SUBMISSION_TEMPLATE.md) — the proof-certificate template.

The public leaderboard is at <https://kz99.github.io/binary-gv-concrete-observatory/#/record>.
